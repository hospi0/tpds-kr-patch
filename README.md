# 테마파크 DS 한글 패치

> **내려받기:** [릴리즈 페이지](https://github.com/hospi0/tpds-kr-patch/releases/latest) — 최신 v0.9. 적용 방법·원본 MD5 는 패치 묶음의 readme 에 있습니다.

Theme Park DS (NDS 북미판, A8QE)의 비공식 한글 패치입니다.

## 바뀌는 것

- 게임 안 글 전부 한국어(메뉴·메시지·조언자 4명 대사·튜토리얼·제작진 직함) — 언어 선택의 일본어 자리가 «한국어»
- 처음 켜면 한국어로 시작(본체 언어 설정과 상관없이)
- 동그라미·V 표시를 그려서 고르던 버튼을 **터치 한 번**으로 고를 수 있음(그리는 방식도 그대로 됨)
- 이름 입력 자판 한글(한글1·한글2 두 쪽, 영문은 «Aa» 탭)

## 알려진 사항

- 이름 입력 자판은 칸 수 때문에 쓸 수 있는 음절이 정해져 있습니다(한글 94자).
- 자판 아래 탭의 «あ» 아이콘은 원문 그대로입니다.
- 원본으로 만든 세이브스테이트를 불러오면 원본 상태로 돌아갑니다. 새로 부팅하세요.

## 저장소 내용

ROM·세이브스테이트·빌드 결과물은 올리지 않습니다.

- `tools/` — 추출·빌드 도구(`build.py`: 원본 ROM → 한글판, `tapfix.py`: 제스처→탭·기본 언어, `kbdko.py`·`kbdgfx.py`: 자판)
- `work/text/` — 원문(EN·JP) 추출본, `work/ko/` — 한국어 번역
- `docs/` — 조사·작업 기록(`01_초기조사.md`, 이어하기 `00_이어하기.md`)
