## 2. 번역할 텍스트 (`work/text/*.tsv` — 전량 추출본)
| 파일 | 줄 | 내용 |
|---|---|---|
| LANG0.tsv | 997 | 메뉴·UI·메시지·조언자 소개 |
| advice0‥3.tsv | 각 315 | 조언자 대사 — **4명 말투가 다름**(JP 기준 같은 줄 56뿐) |
| credits.tsv | 137 | 제작진(대부분 영문 이름 — 직함만 번역) |

열: 묶음 · 번호 · 식별자(COD) · EN · JP · **KO(비어 있음)**. `\n` = 줄바꿈, `<P>` = 쪽 넘김.
- 번역은 **JP 기준**(한국어 = JP 자리 교체), EN 은 뜻 확인용.
- 작업 방식: `work/text/X.tsv` 를 `work/ko/X.tsv` 로 복사해 KO 열을 채운다(검사기·빌더가 열 수로 알아본다). PoC 파일 `00_poc.tsv`(파일·묶음·번호·KO 4열)와 겹치는 줄은 한쪽만 남길 것(빌더가 중복이면 멈춘다).
- 조언자: 0 = 리(22세, 신진기예) · 1 = Mr.벨(58세, 박학다재) · 2 = 크리스탈(26세, 재색겸비) · 3 = 모카(18세, 순진무구) — advice3 = 모카 **실기 확인**(나머지 0‥2 대응은 추정). 말투를 JP 에 맞춰 네 벌로.

## 3. 조판 규칙 (검사기 `python tools/kocheck.py` 가 막는다 — 배치마다 돌릴 것)
- 대사창 한 줄 = **220px(전각 22자)**, 한 쪽 **3줄**. 한글 10px · 반각(영숫자·ASCII 부호) 5px · 공백 4px 로 계산.
- 줄은 `\n` 으로 직접 끊는다(JP 처럼). 낱말 한복판에서 끊지 말 것.
- `%s` `%d` `<1>` `<2>` `<P>` `＠＠＠＠` 는 원문과 개수가 같아야 한다.
- 문장부호(, . ! ? : ;) 뒤 공백은 **빌더가 지운다**(전 프로젝트 규칙) — 폭 계산도 지운 뒤 기준.
- 번역에 가나·한자를 남기지 말 것(글꼴 한자 칸을 한글로 쓴다).
- 일본어 고유명사는 거센소리(か=카, た=타, つ=츠).
- 메뉴·표 항목(짧은 줄)은 원문 폭(JP 글자 수)을 넘지 않게 — 칸이 좁다(검사기는 아직 대사창 폭만 본다).
- 용어는 PS1 테마파크 계열 한글판과 맞춘다(로컬 `tp-ps1-kr-patch`·`tpw-ps1-kr-patch` 용어표 — 이 저장소엔 없음). PoC 에서 정한 것: アトラクション=어트랙션, ショップ=상점, スタッフ=직원, 興奮度=흥분도, 耐久性=내구성, 定員数=정원, すれちがい通信=엇갈림 통신, 総資金=총자금.
- 번역 줄은 셸 이스케이프 말고 편집기로 직접 쓸 것(음절이 깨진다).
